Dans Gmail

  1. Roue dentée en haut à droite, puis Voir tous les paramètres.
  2. Onglet Général, descendre jusqu'à Signature.
  3. Créer, la nommer Grafycom.
  4. Cliquer dans le cadre et coller avec Ctrl+V.
  5. Dessous, choisir cette signature pour les nouveaux messages et pour les réponses.
  6. Tout en bas de la page : Enregistrer les modifications.

Le réglage par défaut de Gmail insère la signature sous le texte cité quand vous répondez. La case « Insérer la signature avant le texte cité », juste en dessous, corrige ça : sans elle, votre signature se retrouve en bas d'un fil de douze messages.

Ce qu'il faut savoir

Le logo peut ne pas s'afficher

Beaucoup de messageries bloquent les images tant que le destinataire ne les autorise pas. C'est voulu : la signature reste entière sans lui, le texte ne dépend d'aucune image.

Le dégradé n'est pas une image

Le filet est fait de huit cellules de tableau, une par couleur de la charte. Un vrai dégradé CSS disparaîtrait sous Outlook ; celui-ci s'affiche partout.

Les polices ne sont pas celles du site

Playfair et Inter ne s'installent pas chez le destinataire. Georgia et Arial les remplacent : présentes partout, et Georgia est le serif qui approche le mieux Playfair.
